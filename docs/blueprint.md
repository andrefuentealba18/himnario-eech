# **App Name**: Himnario EECH Móvil

## Core Features:

- Búsqueda de Himnos: Permite a los usuarios buscar himnos por título, número o palabra clave.
- Visualización de Letras: Muestra las letras de los himnos en una interfaz fácil de leer, con opciones para ajustar el tamaño de la fuente.
- Índice de Himnos: Proporciona un índice alfabético y numérico de todos los himnos disponibles.
- Himnos Favoritos: Permite a los usuarios guardar sus himnos favoritos en una lista personalizada para un acceso rápido.

## Style Guidelines:

- Color primario: Azul suave (#A0C4FF) para reflejar la paz y la espiritualidad.
- Color de fondo: Blanco (#FFFFFF) para claridad y facilidad de lectura.
- Color de acento: Amarillo dorado (#FFD700) para resaltar elementos importantes y acciones.
- Fuente para cuerpo del texto y títulos: 'Alegreya', una fuente serif para mantener un estilo elegante.
- Iconos simples y claros para facilitar la navegación y la comprensión de las funciones de la aplicación.
- Diseño limpio y organizado, priorizando la facilidad de uso y la accesibilidad en dispositivos móviles.
- Transiciones suaves y sutiles al navegar entre himnos y funciones para una experiencia de usuario agradable.
