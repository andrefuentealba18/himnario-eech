# Preview Project

This workflow describes how to start the development server to preview the Next.js project.

1.  **Environment Check**: Verify Node.js environment (>= v20.x.x) is loaded.
    *   If using nvm: `nvm use 24`
2.  **Dependencies**: Ensure dependencies are installed by running `npm install`.
3.  **Preview**: Run `npm run dev` to start the Turbopack development server.
4.  **Visualize**: Access the application at `http://localhost:3000` in your web browser.
