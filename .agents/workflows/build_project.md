# Build Project

This workflow describes how to build the Next.js project.

1.  **Environment Check**: Verify Node.js environment (>= v20.x.x) is loaded.
    *   If using nvm: `nvm use 24`
2.  **Dependencies**: Run `npm install` to install dependencies.
3.  **Build**: Run `npm run build` to build the Next.js project for production.
